# LyricSplash

LyricSplash is a simple Python-based application that fetches and displays song lyrics in a clean, user-friendly way. This repository contains the open-source code that powers the LyricSplash app.

## Features

* Fetches lyrics for songs
* Lightweight and easy to run
* Built with Python
* Open-source and customizable

## Prerequisites

Before you begin, make sure you have the following installed on your system:

* Python 3.8 or higher
* Git
* pip (Python package manager)

## Installation

### 1. Clone the Repository

First, clone the repository from GitHub:

```bash
git clone https://github.com/praveenkurup/lyricsplash.git
```

Then navigate into the project directory:

```bash
cd lyricsplash
```

### 2. Create a Virtual Environment (Optional but Recommended)

```bash
python -m venv venv
```

Activate it:

* On macOS / Linux:

```bash
source venv/bin/activate
```

* On Windows:

```bash
venv\\Scripts\\activate
```

### 3. Install Python Requirements

Install the required dependencies using pip:

```bash
pip install -r requirements.txt
```

## Running the Application

Once all dependencies are installed, start the app by running:

```bash
python main.py
```

The application should now be running locally.

## Project Structure

* `main.py` – Entry point of the application
* `requirements.txt` – Python dependencies
* Other supporting modules and assets
